# AI Property Assistant

AI Property Assistant is a full-stack prototype for property search, inspection booking, booking lookup, and chatbot support.

## Technologies Used

- React.js for frontend
- FastAPI for backend
- Python virtual environment
- Git and GitHub for version control

## Main Features

1. Property listings from backend API
2. Property search filtering by location, property type, and budget
3. Inspection booking form
4. Booking confirmation ID
5. Retrieve booking details using booking ID
6. AI chatbot frontend connected to backend `/chat` endpoint
